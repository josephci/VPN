# 常見疑問

## 會唔會爆錢？邊度睇？

升咗 Pay As You Go 之後，**理論上有機會產生費用**，但實際風險唔係你諗嗰樣。

**流量幾乎唔可能爆。** Always Free 每月 **10TB 出站** —— 大約等於連續睇 1000 小時 4K 串流。個人用途一年都用唔完一個月額度。

**真正嘅風險係唔覺意開咗收費資源：**

- 開咗冇 `Always Free-eligible` 標籤嘅 shape（`VM.Standard.E5.Flex` 就係收費嗰隻）
- **終止實例時冇刪 boot volume** —— 開機失敗過幾次嘅話特別容易中

```
Storage → Block Volumes → 睇下有冇孤兒 boot volume
```

Always Free 總共 **200GB**，每個 boot volume 預設 50GB。留低幾個唔用嘅就會超額。

### 兩個地方睇

| 睇乜 | 去邊 |
|---|---|
| 實際使唔使錢 | `Billing & Cost Management` → **`Cost Analysis`**（正常應該 **$0.00**）|
| 預先警報 | `Billing` → **`Budgets`** → 設 **US$1** 警報 |

> 💡 **部署完即刻去設個 US$1 Budget alert。** 一有收費就 email 通知，唔使等月結先發現。

## 其他人會唔會連到入我部機？

### 陌生人用唔用到我個代理？唔會。

VLESS 要**正確 UUID**，Hysteria2 要**正確密碼**。冇呢兩樣，REALITY 只會將佢哋轉去真嘅偽裝網站。

你會喺 log 見到一堆陌生 IP 出 `processed invalid connection` —— 嗰啲係互聯網掃描器，**佢哋見到嘅係一個普通網站**，完全唔知後面有代理。呢個正正證明偽裝生效緊。

### 陌生人入唔入到我部伺服器？好難。

SSH 22 對全世界開住，但 Oracle 嘅 Ubuntu image **預設關咗密碼登入，只接受金鑰**。冇你個私鑰，暴力破解冇用。

### 唯一真正嘅風險：你自己漏咗條連結

條 `vless://` 連結入面就係 UUID 同公鑰 —— **等於一條鎖匙**。任何人攞到就用得到你部機，而所有流量都掛喺你個 IP 上。

- ❌ 唔好貼上論壇、群組、GitHub
- ❌ 唔好用第三方「訂閱轉換」網站（會攞到你全部憑證）
- ✅ 想收返權限就 `sudo rm /etc/sing-box/params.env && sudo bash scripts/deploy.sh` 重新生成

## 兩個協議都唔得可以點？

按次序試：

**① 換 IP（最常見有效，甲骨文免費）**

九成九「用咗一排突然斷」都係 IP 被封。步驟見 [`maintenance.md`](maintenance.md#換-ip)。

**② 換偽裝目標／端口**

```bash
sudo bash scripts/deploy.sh --reality-sni dl.google.com
```

**③ 開第二個出口（最重要嘅長遠保險）**

同一套腳本跑喺另一部機、另一間供應商、另一個地區。兩個 IP 同時被封嘅機會低好多。見 [`maintenance.md`](maintenance.md#建立第二個出口強烈建議)。

**④ 免費保底 —— 而家就裝定**

| 工具 | 特點 |
|---|---|
| **Psiphon（賽風）** | 免費開源，自動輪換協議，專為審查環境設計 |
| **Cloudflare WARP** | 免費，偶爾通 |
| **Tor + Snowflake 網橋** | 慢，但設計上最難封死 |

> ⚠️ 呢三個**要而家就裝好喺手機同電腦**。等到斷網先想搵，你根本落唔到。

**⑤ 敏感時期**（兩會、重要會議前後）封鎖會收緊，REALITY 可能唔穩 —— **Hysteria2 通常撐得耐啲**，先試佢。

## 人喺境外，點測內地用唔用到？

### ① 由內地節點測你個 IP（即刻做得到）

用內地撥測網站，由全國幾十個節點連你個 IP。推薦 **[itdog.cn](https://www.itdog.cn/)**：

1. 揀 **「TCP端口检测」**
2. 輸入你個 IP，端口 **443**
3. 節點揀「**全国**」→ 開始

| 結果 | 代表 |
|---|---|
| 大部分**綠色／連通** | ✅ IP 未被封，好大機會用得到 |
| 大部分**紅色／超時** | ❌ IP 已被封，[換 IP](maintenance.md#換-ip) |
| 部分通部分唔通 | ⚠️ 某啲省份／營運商封咗 |

> 🔴 **一定要用「TCP端口检测」，唔好用 Ping。**
> **Oracle 預設封 ICMP**，ping 一定唔通 —— 咁唔代表 IP 被封。用 ping 測會得出錯誤結論。

同類工具：[ping.chinaz.com](https://ping.chinaz.com/)、[boce.com](https://www.boce.com/)

**局限**：只測到「IP 通唔通」，測唔到「隧道通唔通」。不過實務上 REALITY 主要就係死喺 IP 被封，所以已有八成參考價值。

### ⚠️ ② 最大陷阱：唔好用漫遊測試

**境外 SIM 開漫遊入內地，流量係經返本地營運商出去，根本唔經 GFW。** 你會發現乜都通，一換內地 SIM 或者連內地 WiFi 就即刻唔通。

- ❌ 港澳 SIM 漫遊 → 測試**無效**
- ✅ 內地 SIM（移動／電信／聯通）→ 有效
- ✅ 內地 WiFi → 有效

### ③ 最準確：搵內地嘅人實測

將兩條連結俾信得過嘅人，叫佢裝 NekoBox / Shadowrocket，連線後開 https://ip.sb 睇 IP。

要求佢試埋：**兩個協議分開試**、**手機數據同 WiFi 都試**（唔同營運商差好遠），記低佢用邊間營運商、邊個省。

> ⚠️ 條連結等於鎖匙，只俾信得過嘅人。想收返權限就重新生成金鑰。

### ④ 自己到咗內地之後

```
1. 先試 REALITY
   ↓ 唔通
2. 切 Hysteria2
   ↓ 唔通
3. 換手機數據／WiFi 再試（唔同網絡差好遠）
   ↓ 唔通
4. 開 Psiphon 或 WARP 應急，用佢登入 Oracle Console 換 IP
```

**第 4 步係關鍵**：你需要一個能上網嘅方法先登入到 Oracle 換 IP。**Psiphon 一定要入境前裝好**，佢就係救生艇。

### ⑤ 日常監測

每隔一排用 itdog 測一次，IP 一被封即刻知，唔使等到要用嗰陣先發現。

## 點解普通 VPN（IPsec / WireGuard / PPTP）喺內地唔得？

常見經歷：**完全連唔到**，或者**連一陣就斷**。呢個唔係設定錯，係嗰啲協議喺內地根本冇得用。

### 佢哋「大聲宣告自己係 VPN」

呢啲協議**唔係為對抗審查而設計**嘅 —— 前提係「網絡係中立嘅」。企業內部用冇問題，一過 GFW 就死。

| 協議 | 用咩 | 點解一眼被認出 |
|---|---|---|
| **PPTP** | TCP 1723 + **GRE（協議 47）** | GRE 日常上網根本唔會出現 |
| **L2TP/IPsec、IKEv2** | **UDP 500、4500** + ESP | IKE 握手包**結構固定**，開頭幾個 byte 就出賣自己 |
| **OpenVPN** | 端口可自選 | 握手有固定 opcode，改端口冇用 |
| **WireGuard** | UDP 自選端口 | **握手包首 byte 固定 0x01/0x02，長度固定 148/92 bytes** |

> 🔴 **改端口係冇用嘅。** GFW 睇嘅係**封包內容結構**（DPI，深度封包檢測），唔係端口號。

### 「連一陣就斷」嘅機制

GFW **需要時間先認得出你**：

```
① 發出握手 → 頭幾個包過咗（DPI 未判斷完）
② 隧道建立，你以為成功咗，開始有得用
③ DPI 完成分類：「呢條係 VPN 隧道」
④ 開始丟包 / 注入 RST → 連線突然唔郁
⑤ 伺服器 IP 可能被「臨時黑洞」幾分鐘到幾個鐘
   → 重連又唔得，等陣又得返 → 「有時得有時唔得」
```

**兩種阻斷手法：**

- **TCP 類** → GFW **偽造 RST 封包**同時射俾兩邊，連線「啪」一聲即斷
- **UDP 類**（IPsec、WireGuard）→ 冇 RST 可言，**直接丟包**，連線 hang 住然後 timeout

唔同省份、營運商、時段嘅執行力度唔一樣，所以會有「琴日得今日唔得」「WiFi 得數據唔得」—— 唔係玄學，係策略唔統一。

### DDNS 域名嘅獨立問題

用 `xxx.asuscomm.com` 之類嘅 DDNS **唔係主因**，但有兩個附加問題：

1. **更新延遲** — 屋企 IP 變咗，DDNS 更新 + DNS 快取 TTL 要時間，呢段時間你連緊舊 IP
2. **DNS 污染風險** — GFW 會對某啲域名注入**偽造 DNS 回應**，而且比真回應快，你部機信先到嗰個

但就算 DNS 完全正常、IP 完全正確，**IPsec 一樣會死喺協議層**。

### 技術路線嘅演進

| 世代 | 思路 | 結果 |
|---|---|---|
| **IPsec / WireGuard** | 「我係 VPN，我照跑」 | 特徵明顯，DPI 一眼認出 |
| **Shadowsocks 早期** | 「我扮成隨機數據」 | ⚠️ **隨機本身就係特徵** —— 正常流量唔會成條都係高熵亂數，GFW 反而靠「太隨機」認你 |
| **VMess / obfs** | 「我加多層混淆」 | 加咗嘢就有得學，最後被摸清 |
| **VLESS-REALITY** | **「我就係一個真嘅 HTTPS 連線」** | 冇加任何嘢，借真網站 TLS 握手 |
| **Hysteria2** | 「我係 Chrome 上 Google 嘅 QUIC」 | 混入海量正常 HTTP/3 流量 |

> **最核心一課：對抗審查唔係「加密得夠強」，係「睇落同正常流量一模一樣」。**
>
> IPsec 加密強度其實好高，內容 GFW 睇唔到 —— 但佢**唔使睇內容，睇個信封就夠**。

## 咁買 Surfshark / NordVPN 呢啲得唔得？

**預設模式一定唔得** —— 佢哋用 OpenVPN / WireGuard / IKEv2，全部係上面列嘅「一眼被認出」嗰批。

大廠都知，所以有加料模式：Surfshark 嘅 **NoBorders + Camouflage**、NordVPN 嘅 **Obfuscated Servers**、**Astrill 嘅 StealthVPN**（內地口碑最好）、Mullvad 嘅 WireGuard over Shadowsocks。呢啲混淆**普遍比 REALITY 落後一代**（多數係「包一層 TLS」，而唔係「借用真 TLS」）。

### 但真正嘅死因係：IP 係公開嘅

**任何協議混淆都救唔到呢一點。**

商業 VPN 有幾千部伺服器、幾百萬用戶，而**伺服器 IP 清單就寫喺佢個 app 同官網度**。GFW 想封佢根本唔使用 DPI：

```
落載個 app → 攞到成份伺服器清單 → 整段 IP 加黑名單 → 完
```

一次過封曬。混淆得幾好都冇用，因為**你連唔到嗰個 IP**。

| | 商業 VPN | 自建 |
|---|---|---|
| **IP 曝光度** | 公開、幾百萬人共用 | **只有你知** |
| GFW 點封 | 下載佢個清單，整段封 | 要單獨探測到你先封得到 |
| 協議 | 標準協議 + 舊式混淆 | REALITY / Hysteria2 |
| 被封之後 | 等佢加新伺服器（幾日～幾星期）| **自己換 IP，幾分鐘** |
| 月費 | US$3–13 | **$0** |
| 私隱 | 要信佢唔記錄 | 自己控制 |

### 兩個實際問題

1. **入境後裝唔到、更新唔到** —— app 喺中國區 App Store 落咗架，官網又被封
2. **商業服務係高可見度目標** —— GFW 主動針對有規模嘅供應商；你一個自用節點喺佢眼中係背景雜訊

### 咁佢哋係咪冇用？

**唔係，只係唔適合對付 GFW。** 外國公共 WiFi 保護、串流解鎖、唔想俾本地 ISP 睇到瀏覽記錄 —— 呢啲場景好好用。

真係想買個後備，**Astrill** 內地口碑最好，但貴（約 US$15–25/月），敏感時期一樣會斷。

**免費 VPN 更加唔使諗** —— 通常連混淆都冇，IP 共用更誇張，而且靠賣你嘅流量數據賺錢。

> **一句總結：商業 VPN 輸唔係輸在加密，係輸在佢個地址簿係公開嘅。**
> 自建嘅最大價值唔係技術更先進，係**冇人知你部機存在** —— 而且被發現咗，你三分鐘換到個新身份。

## 反方向：喺境外想睇內地限區內容（「回國」）

方向啱啱相反 —— 你需要一個**內地 IP**。免費選擇比翻牆少好多，原因見下。

### ① 先試官方海外版（最簡單，唔使任何代理）

| 平台 | 海外版 |
|---|---|
| 愛奇藝 | **iQIYI 國際版**（iq.com）|
| 騰訊視頻 | **WeTV** |
| 優酷 | 優酷海外版 |
| 芒果TV | 芒果TV國際版 |
| B站 | 部分內容有港澳台區 |

片庫唔同（版權分區），但熱門劇同綜藝通常都有，而且合法、速度快。**先查你要睇嗰套喺唔喺度** —— 有嘅話就唔使搞任何嘢。

### ② 免費「回國」工具

**穿梭 Transocks**、**快帆 SpeedIn** 等有免費檔位，一般係限速 + 限時 + 有廣告。付費約 ¥15–30/月。

> 條款同免費額度成日變，落載前自己睇清楚。

### ⚠️ 風險比翻牆工具高

**你嘅流量會經過內地伺服器** —— 即係喺 GFW 監管範圍內，同時俾服務商睇到。免費嘅點賺錢？同免費 VPN 一樣：賣數據、插廣告、賣頻寬。

- ✅ 淨係開嚟睇片，睇完熄
- ❌ **唔好開住佢登入 Gmail、銀行、公司系統**
- ❌ 唔好同翻牆嘅嘢同時開
- ✅ 用「僅代理指定應用」模式，唔好全局代理

### ③ 自建得唔得？可以，但唔划算

**要錢 + 要實名** — 阿里雲／騰訊雲輕量約 ¥24–38/月，要身份證／護照 + 內地手機號，冇免費層。

**機房 IP 會被識別** — 呢個先係關鍵。串流平台**主動封鎖已知機房 IP 段**（同 Netflix 封 VPN 一樣）。阿里雲個 IP 一睇就知係數據中心，好大機會播唔到。

**商業回國服務反而有優勢** — 佢哋有部分用住宅 IP，唔容易被識別。

### 「翻牆」同「回國」最大嘅分別

| | 翻牆 | 回國 |
|---|---|---|
| 對手 | GFW（睇**協議特徵**）| 串流平台（睇 **IP 類型**）|
| 自建有冇優勢 | ✅ **有** — 你個 IP 冇人知 | ❌ **冇** — 機房 IP 一睇就知 |
| 免費方案 | Oracle 永久免費 | 冇真正免費嘅自建路 |

> **建議次序**：官方海外版 → 免費回國工具 → 付費回國服務（¥15–30/月）。
> **唔建議自建** —— 呢次係少有嘅「買服務好過自己搞」。

## 原理係咪「偽裝成 apple 去連外網」？

**一半啱。** 偽裝只係喺**握手嗰一刻**，你嘅流量唔會經過 Apple。

```
① 你部裝置 → 你部伺服器:443
   發一個 TLS ClientHello，SNI 寫住 www.apple.com

② 你部伺服器 → 真・www.apple.com
   將握手轉發過去，借返 Apple 嘅真實憑證

③ 分岔：
   ├─ 有正確金鑰 → 伺服器喺握手後「劫持」條連線，變成你嘅加密隧道
   └─ 冇金鑰（GFW 探測器）→ 繼續轉發去真 apple.com
      探測器見到貨真價實嘅蘋果網站，憑證鏈都驗得過

④ 你真正嘅流量：
   你部裝置 →（加密）→ 你部伺服器 → 目標網站
```

**幾個關鍵：**

- **Apple 見唔到你嘅流量**，佢只參與握手嗰一下
- **出口 IP 係你伺服器嘅 IP**，唔係 Apple 嘅
- 準確講法唔係「經過 apple 上網」，係「**扮緊喺上 apple**」

所以偽裝目標揀邊個，唔影響速度同私隱，只影響**扮得似唔似**（同埋借唔借得到 —— 見 [`troubleshooting.md`](troubleshooting.md) 嗰個 `www.microsoft.com` 嘅坑）。

### Hysteria2 唔同

佢冇借任何嘢，係將自己嘅 QUIC 流量偽裝成 Chrome 上 Google 嘅正常 HTTP/3 流量，用密碼認證 + 自簽憑證。

**兩個協議唔會同時被同一種手法破解** —— 呢個就係要開兩個嘅原因。

# 常見疑問

## 會唔會爆錢？邊度睇？

升咗 Pay As You Go 之後，**理論上有機會產生費用**，但實際風險唔係你諗嗰樣。

**流量幾乎唔可能爆。** Always Free 每月 **10TB 出站** —— 大約等於連續睇 1000 小時 4K 串流。個人用途一年都用唔完一個月額度。

**真正嘅風險係唔覺意開咗收費資源：**

- 開咗冇 `Always Free-eligible` 標籤嘅 shape（`VM.Standard.E5.Flex` 就係收費嗰隻）
- **終止實例時冇刪 boot volume** —— 開機失敗過幾次嘅話特別容易中

```
Storage → Block Volumes → 睇下有冇孤兒 boot volume
```

Always Free 總共 **200GB**，每個 boot volume 預設 50GB。留低幾個唔用嘅就會超額。

### 兩個地方睇

| 睇乜 | 去邊 |
|---|---|
| 實際使唔使錢 | `Billing & Cost Management` → **`Cost Analysis`**（正常應該 **$0.00**）|
| 預先警報 | `Billing` → **`Budgets`** → 設 **US$1** 警報 |

> 💡 **部署完即刻去設個 US$1 Budget alert。** 一有收費就 email 通知，唔使等月結先發現。

## 其他人會唔會連到入我部機？

### 陌生人用唔用到我個代理？唔會。

VLESS 要**正確 UUID**，Hysteria2 要**正確密碼**。冇呢兩樣，REALITY 只會將佢哋轉去真嘅偽裝網站。

你會喺 log 見到一堆陌生 IP 出 `processed invalid connection` —— 嗰啲係互聯網掃描器，**佢哋見到嘅係一個普通網站**，完全唔知後面有代理。呢個正正證明偽裝生效緊。

### 陌生人入唔入到我部伺服器？好難。

SSH 22 對全世界開住，但 Oracle 嘅 Ubuntu image **預設關咗密碼登入，只接受金鑰**。冇你個私鑰，暴力破解冇用。

### 唯一真正嘅風險：你自己漏咗條連結

條 `vless://` 連結入面就係 UUID 同公鑰 —— **等於一條鎖匙**。任何人攞到就用得到你部機，而所有流量都掛喺你個 IP 上。

- ❌ 唔好貼上論壇、群組、GitHub
- ❌ 唔好用第三方「訂閱轉換」網站（會攞到你全部憑證）
- ✅ 想收返權限就 `sudo rm /etc/sing-box/params.env && sudo bash scripts/deploy.sh` 重新生成

## 兩個協議都唔得可以點？

按次序試：

**① 換 IP（最常見有效，甲骨文免費）**

九成九「用咗一排突然斷」都係 IP 被封。步驟見 [`maintenance.md`](maintenance.md#換-ip)。

**② 換偽裝目標／端口**

```bash
sudo bash scripts/deploy.sh --reality-sni dl.google.com
```

**③ 開第二個出口（最重要嘅長遠保險）**

同一套腳本跑喺另一部機、另一間供應商、另一個地區。兩個 IP 同時被封嘅機會低好多。見 [`maintenance.md`](maintenance.md#建立第二個出口強烈建議)。

**④ 免費保底 —— 而家就裝定**

| 工具 | 特點 |
|---|---|
| **Psiphon（賽風）** | 免費開源，自動輪換協議，專為審查環境設計 |
| **Cloudflare WARP** | 免費，偶爾通 |
| **Tor + Snowflake 網橋** | 慢，但設計上最難封死 |

> ⚠️ 呢三個**要而家就裝好喺手機同電腦**。等到斷網先想搵，你根本落唔到。

**⑤ 敏感時期**（兩會、重要會議前後）封鎖會收緊，REALITY 可能唔穩 —— **Hysteria2 通常撐得耐啲**，先試佢。

## 人喺境外，點測內地用唔用到？

### ① 由內地節點測你個 IP（即刻做得到）

用內地撥測網站，由全國幾十個節點連你個 IP。推薦 **[itdog.cn](https://www.itdog.cn/)**：

1. 揀 **「TCP端口检测」**
2. 輸入你個 IP，端口 **443**
3. 節點揀「**全国**」→ 開始

| 結果 | 代表 |
|---|---|
| 大部分**綠色／連通** | ✅ IP 未被封，好大機會用得到 |
| 大部分**紅色／超時** | ❌ IP 已被封，[換 IP](maintenance.md#換-ip) |
| 部分通部分唔通 | ⚠️ 某啲省份／營運商封咗 |

> 🔴 **一定要用「TCP端口检测」，唔好用 Ping。**
> **Oracle 預設封 ICMP**，ping 一定唔通 —— 咁唔代表 IP 被封。用 ping 測會得出錯誤結論。

同類工具：[ping.chinaz.com](https://ping.chinaz.com/)、[boce.com](https://www.boce.com/)

**局限**：只測到「IP 通唔通」，測唔到「隧道通唔通」。不過實務上 REALITY 主要就係死喺 IP 被封，所以已有八成參考價值。

### ⚠️ ② 最大陷阱：唔好用漫遊測試

**境外 SIM 開漫遊入內地，流量係經返本地營運商出去，根本唔經 GFW。** 你會發現乜都通，一換內地 SIM 或者連內地 WiFi 就即刻唔通。

- ❌ 港澳 SIM 漫遊 → 測試**無效**
- ✅ 內地 SIM（移動／電信／聯通）→ 有效
- ✅ 內地 WiFi → 有效

### ③ 最準確：搵內地嘅人實測

將兩條連結俾信得過嘅人，叫佢裝 NekoBox / Shadowrocket，連線後開 https://ip.sb 睇 IP。

要求佢試埋：**兩個協議分開試**、**手機數據同 WiFi 都試**（唔同營運商差好遠），記低佢用邊間營運商、邊個省。

> ⚠️ 條連結等於鎖匙，只俾信得過嘅人。想收返權限就重新生成金鑰。

### ④ 自己到咗內地之後

```
1. 先試 REALITY
   ↓ 唔通
2. 切 Hysteria2
   ↓ 唔通
3. 換手機數據／WiFi 再試（唔同網絡差好遠）
   ↓ 唔通
4. 開 Psiphon 或 WARP 應急，用佢登入 Oracle Console 換 IP
```

**第 4 步係關鍵**：你需要一個能上網嘅方法先登入到 Oracle 換 IP。**Psiphon 一定要入境前裝好**，佢就係救生艇。

### ⑤ 日常監測

每隔一排用 itdog 測一次，IP 一被封即刻知，唔使等到要用嗰陣先發現。

## 原理係咪「偽裝成 apple 去連外網」？

**一半啱。** 偽裝只係喺**握手嗰一刻**，你嘅流量唔會經過 Apple。

```
① 你部裝置 → 你部伺服器:443
   發一個 TLS ClientHello，SNI 寫住 www.apple.com

② 你部伺服器 → 真・www.apple.com
   將握手轉發過去，借返 Apple 嘅真實憑證

③ 分岔：
   ├─ 有正確金鑰 → 伺服器喺握手後「劫持」條連線，變成你嘅加密隧道
   └─ 冇金鑰（GFW 探測器）→ 繼續轉發去真 apple.com
      探測器見到貨真價實嘅蘋果網站，憑證鏈都驗得過

④ 你真正嘅流量：
   你部裝置 →（加密）→ 你部伺服器 → 目標網站
```

**幾個關鍵：**

- **Apple 見唔到你嘅流量**，佢只參與握手嗰一下
- **出口 IP 係你伺服器嘅 IP**，唔係 Apple 嘅
- 準確講法唔係「經過 apple 上網」，係「**扮緊喺上 apple**」

所以偽裝目標揀邊個，唔影響速度同私隱，只影響**扮得似唔似**（同埋借唔借得到 —— 見 [`troubleshooting.md`](troubleshooting.md) 嗰個 `www.microsoft.com` 嘅坑）。

### Hysteria2 唔同

佢冇借任何嘢，係將自己嘅 QUIC 流量偽裝成 Chrome 上 Google 嘅正常 HTTP/3 流量，用密碼認證 + 自簽憑證。

**兩個協議唔會同時被同一種手法破解** —— 呢個就係要開兩個嘅原因。
